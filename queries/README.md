# Query workloads

One query per line: `id=17 k=4 edges=0>1,1>2,1>3 preds=0:pu<0.001;2:label=15;3:pd<0.01`.
`a>b` is a pattern edge traversed through the out-adjacency of `a`. Predicates: `pu<s` (uniform
property, selectivity exactly s), `pd<s` (top-s fraction of highest-degree vertices), `label=L`
(ground-truth community). Semantics are homomorphisms (SQL self-joins, Kùzu/Ladybug MATCH, and one
MATCH clause per edge in Neo4j all agree); the result is the match count. Lines starting with `#` are
comments. Generated by `scripts/qgen.py`; subsamples are line subsets of the parent file, so the
parent's `.meta.csv` applies to them.
